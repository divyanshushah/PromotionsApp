**Project Name and Description**
- **Project:** `PromotionsApp` — Promotions Rule Engine
- **Purpose:** A small rule engine that calculates promotional pricing for items in a checkout cart. The engine applies different promotion rules (e.g., N-units, mix-sku promotions) against inventory pricing and active promotions to compute the final cart total.

**Technology Stack**
- **Language & Runtime:** C# targeting `.NET 9.0` (`net9.0`).
- **Test frameworks & tools:** `xUnit`, `Moq`, `FluentAssertions`, `coverlet.collector` (see `PromotionAppTest/PromotionApp.Test.csproj`).

**Project Architecture**
- The app is organized as a small multi-project solution (`PromotionsApp.sln`) containing the main application and tests.
- Core structure:
  - `Promotion.Domain` — domain DTOs and rule implementations (interfaces and concrete rules like `NunitsSkuRule`, `MixSkuRule`, `BasicRule`).
  - `Promotion.Repository` — repository abstraction and a demo `DbRepository` that provides active promotions and inventory unit prices.
  - `Promotion.GUI` — a small console runner (`Program.cs`) demonstrating how to attach rules and execute the engine.
- The rule engine (`Promotion.Domain/Rules/PromotionRuleEngine.cs`) accepts a collection of `IRule` implementations and applies each active rule to the `CheckOutCartDto` to calculate `TotalPrice`.
